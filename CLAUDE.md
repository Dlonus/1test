## Project Overview

This is a Godot 3.x project (config_version=4). The project is named "1test" and uses the Godot scene format version 2.

## Engine & Build

- **Engine:** Godot 3.x (not 4.x — uses `config_version=4` in project.godot, `.tscn` format=2, and `Transform` instead of `Transform3D`)
- **Run from editor:** Open `project.godot` in the Godot editor and press F5 (or F6 for current scene)
- **Run from CLI:** `godot --path /home/dlon/stu/1test` (requires Godot 3.x binary in PATH)

## Scene Structure

- `Spatial.tscn` — Root 3D scene with a single Spatial node
- `the layuh.tscn` — A 3D layout/level with a floor and walls built from scaled CubeMesh instances
- `default_env.tres` — Default environment resource (procedural sky)

## Godot 3.x Conventions

- Scripts use GDScript (`.gd` files) — none exist yet
- Scene files use `.tscn`, resources use `.tres`
- 3D node types: `Spatial`, `MeshInstance`, `KinematicBody`, `RigidBody`, etc. (Godot 4 renamed these)
- The `.import/` directory is auto-generated by the editor; do not edit manually
